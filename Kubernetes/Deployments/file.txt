how to complete a deployment

# Help to create a deployment
=> k create deployment -h | less 

# Create a deployment with 3 replicas
=> k create deployment <Pod name> --image=httpd --replicas=3

# Delete a deployment with 3 replicas
=> k delete deployment.apps <podname>

# display the deployments
=> k get deployments.apps

# Namespace of the deployment
=> k describe deployments.apps

# Edit the deployment
=> k edit deployment.apps

# Notes 
Deployment does not create the replicas sets but controls the replica sets
